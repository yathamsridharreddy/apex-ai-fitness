# APEX AI FITNESS — PRO (Enterprise Commercial Product)
> Designed and engineered to exceed **Fitbod, Nike Training Club, Hevy, Strong, MyFitnessPal, Centr, MuscleWiki, and Freeletics**, featuring an Apple-grade UI design system and multi-package TypeScript architecture.

## 📦 Repository Structure
- `web-application/`: Complete React 18 + Vite + TypeScript + Tailwind CSS + Express + SQLite full-stack website
- `backend-api/`: Production NestJS + TypeScript + PostgreSQL Prisma enterprise API server
- `mobile-app/`: React Native / Expo / TypeScript iOS & Android mobile application
- `standalone-bundles/`: Single-file HTML/JS bundles ready for offline browser viewing

## 🚀 Quick Start
### 1. Web Application (React + Express)
```bash
cd web-application
npm install
npm run server  # Backend starts on port 5000
npm run dev     # Frontend starts on port 3000
```
### 2. Backend API (NestJS)
```bash
cd backend-api
npm install
npm run start:dev
```
### 3. Mobile App (React Native)
```bash
cd mobile-app
npm install
npm start
```
